# Video Craft Studio

個人利用向けの動画設計ダッシュボードです。1本の動画をセクション単位で扱い、視聴者ごとに開始タイミングや強調箇所を変える運用を前提にしています。

## できること

- 視聴者セグメントごとの開始位置を切り替える
- 動画セクションを一覧で管理する
- YouTube公開フローを手順化する
- Config画面でタイトル、開始位置、公開先URL、メモを編集する
- localStorageに保存して次回起動時に復元する

## 使い方

1. `index.html` を開く
2. 視聴者カードを選ぶ
3. `Config` を調整する
4. `Config保存` を押して保存する
