# うめむら半蔵門内科歯科 EDオンライン診療ホームページ プロトタイプ

Codexで作成した、ED治療のオンライン診療・予約枠取得サイトのプロ仕様LPプロトタイプです。

## ファイル

- `index.html`: 3案を切り替えられるLP本体
- `styles.css`: PC / スマホ対応のクリニック向けデザイン
- `script.js`: デザイン候補、予約枠、初診・再診切り替えの操作

## 3つの候補

1. シンプルなバージョン
   - 予約枠、料金、処方薬を最短で見せる広告LP向け。
2. 丁寧に説明したバージョン
   - 初診患者向けに、服用前確認、副作用、禁忌、医師判断を厚めに説明。
3. アニメやイラストレーションを活用したもの
   - 相談しづらさを和らげ、スマホ流入でも親しみやすい印象にする方向性。

## 差し替え前提

- 薬剤名、価格、診察料、送料、配送条件は実運用に合わせて変更してください。
- 薬剤パッケージや処方薬写真は、権利、薬機法、医療広告ガイドラインを確認したうえで掲載してください。
- 予約枠UIはデザイン確認用です。実装時は予約管理、問診、決済、電子カルテ等との連携が必要です。
- 医師名、クリニック名、所在地、特商法表記、プライバシーポリシーは公開前に追加してください。

## 確認方法

`index.html` をブラウザで開くと表示できます。
