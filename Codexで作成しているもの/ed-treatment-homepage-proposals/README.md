# EDオンライン診療ホームページ 3案

Codexで作成した、ED治療のオンライン診療・予約枠取得サイトのプロトタイプです。

## ファイル

- `index.html`: 3案を切り替えて確認できる静的ページ
- `styles.css`: レスポンシブ対応のデザイン
- `script.js`: デザイン候補、予約枠、初診・再診切り替えの簡易操作

## 3つの候補

1. シンプルなバージョン
   - 予約、料金、処方プランにすぐ到達する広告LP向け。
2. 丁寧に説明したバージョン
   - 初診患者向けに、服用前確認・副作用・禁忌・診療フローを厚めに説明。
3. アニメやイラストレーションを活用したもの
   - 相談しづらさを和らげ、スマホ流入でも親しみやすい印象にする方向性。

## 差し替え前提

- 薬剤名、価格、診察料、送料、配送条件は実運用に合わせて変更してください。
- 薬剤パッケージや処方薬写真は、権利、薬機法、医療広告ガイドラインを確認したうえで掲載してください。
- 予約枠UIはデザイン確認用です。実装時は予約管理、問診、決済、電子カルテ等との連携が必要です。

## 確認方法

`index.html` をブラウザで開くと表示できます。
